    spxa Example Gallery

    Browse copy-pasteable examples organized by use case. Every example runs out of the box with pip install spxa — no extra setup required.

    All 45 examples live in examples/ and are tested in CI.

    Core algebra & exact arithmetic

    Example Description Tags
    Process composition & exact triplet arithmetic Compose Lévy processes with +, *, @. Characteristic triplets add in closed form; cumulants derive symbolically. Every result carries a strict exactness level (EXACT → MOMENT → SIMULATION). algebra exactness cumulants
    Bochner subordination & derivation traces Time-change one process by another via X @ Y. Generate plain-text and LaTeX derivation stories with __story__() and narrate_latex(). subordination story

    Run the showcase:

    python examples/full_showcase.py

    Stochastic volatility

    Example Description Tags
    Heston stochastic volatility Calibrate and price under the Heston model. Compute machine-precision Greeks (Delta, Gamma, Vega, Rho, Theta) via reverse-mode autodiff — no finite differences. volatility heston greeks
    SABR model & implied volatility smile SABR stochastic volatility with Hagan asymptotic implied volatility. Build skew and term structure from forward, alpha, beta, nu, rho. volatility sabr skew
    Bates: Heston + compound Poisson jumps Stochastic volatility coupled with log-normal Merton jumps. Joint diffusion and jump dynamics for equity smile and term structure. volatility jumps bates
    Rough Bergomi & fractional volatility Rough Bergomi (rBergomi) with power-law short-time skew blow-up, Riemann–Liouville kernels, and fractional Adams–Bashforth–Moulton Riccati solvers. rough-vol rbergomi fractional

    Volatility surfaces & calibration

    Example Description Tags
    SVI / SSVI / eSSVI volatility surfaces Arbitrage-free SVI parametrizations from option quotes. Raw, natural, and jump-wings slices with no-arbitrage conditions, Durrleman diagnostics, and calendar/wing arbitrage checks. surface svi calibration
    Dupire local vol & stochastic local vol Dupire local volatility in implied variance, Andreasen–Huge calibration, and SLV leverage via 2D Fokker–Planck ADI or particle calibration. local-vol dupire slv
    Martingale optimal transport & model risk Model-free bounds via LP or Sinkhorn MOT, static replication, hedge backtests, and Cont's coherent model-risk measures over calibrated model families. model-risk mot bounds

    Interest rates & curves

    Example Description Tags
    Yield curve bootstrapping Dual-curve bootstrapping with log-linear, monotone cubic, and Hagan–West monotone convex interpolation. OIS, swaps, bonds, and forward curve construction. rates curve bootstrap
    Hull–White short-rate model Closed forms, exact simulation, trinomial tree, and PDE engines. Calibrate to swaptions and caps; price Bermudan swaptions with Andersen–Broadie bounds. rates hull-white short-rate
    LIBOR & forward market models LIBOR market model with abcd volatilities, Rebonato correlations, rank reduction, predictor–corrector simulation, and caplet/swaption calibration. rates lmm libor

    PDE & PIDE solvers

    Example Description Tags
    Black–Scholes PDE pricing Finite-difference pricing with Crank–Nicolson + Rannacher start-up. European, digital, American, Bermudan, barriers, discrete dividends, and local volatility. pde black-scholes american
    Heston two-asset ADI PDE Douglas, Craig–Sneyd, modified Craig–Sneyd, and Hundsdorfer–Verwer ADI schemes for Heston and two-asset options with early-exercise LCPs. pde heston adi
    Exponential-Lévy PIDEs Merton, Kou, VG, CGMY, and NIG jump-diffusion PIDEs with moment-matched small jumps and cell-integrated large-jump operators. pde levy pide

    Simulation & backtesting

    Example Description Tags
    QMC, MLMC & variance reduction Quasi-Monte Carlo (Sobol), multilevel Monte Carlo, antithetic variates, control variates, importance sampling, and stratified sampling backends. simulation qmc mlmc
    Bridges & first-passage times Brownian and OU bridges via Doob's h-transform, Gamma/Bessel bridges, and exact first-passage-time samplers for Brownian motion. simulation bridge first-passage

    git clone https://github.com/Nityahapani/spxa.git
cd spxa
pip install -e ".[dev]"
python examples/heston_example.py
