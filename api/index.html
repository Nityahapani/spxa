    ExactnessLevel

    from spxa.core import ExactnessLevel

    An enum describing the analytical guarantee attached to a process or result. All arithmetic between two processes produces the minimum level of its operands.

    Member Meaning
    ExactnessLevel.EXACT Lévy–Khintchine triplet known in closed form. Triplet arithmetic is analytically exact.
    ExactnessLevel.MOMENT_PROPAGATION No closed-form triplet. Finite moments tracked where computable.
    ExactnessLevel.SIMULATION_ONLY No analytical handle. Sample paths only.

    Ordering: EXACT < MOMENT_PROPAGATION < SIMULATION_ONLY (where < means "more informative than").

    ExactnessLevel.combine(a, b)  # → ExactnessLevel
# Returns the minimum (most degraded) of two levels.

    Comparison operators <, <=, >, >= work as expected.

    Process

    from spxa.core import Process  # abstract base class

    All stochastic processes in spxa inherit from Process. Every instance is immutable — operators return new process objects, never mutate in place.

    Properties

    process.exactness    # → ExactnessLevel
process.triplet      # → LevyTriplet   (raises ExactnessError if not EXACT)
process.properties   # → ProcessProperties

    Operators

    Z = X + Y            # sum of independent processes
Z = X - Y            # X + (-1)*Y
Z = c * X            # scalar multiplication, c ∈ ℝ \ {0}
Z = X * c            # same as c * X
Z = -X               # negation
Z = X @ T            # subordination: Z_t = X_{T_t}  (T must be a subordinator)
Z = sum([X, Y, ...]) # Python's built-in sum() works via __radd__

    All operators propagate ExactnessLevel and ProcessProperties automatically. If ExactnessLevel degrades, SpxaDegradationWarning is emitted with a mathematical reason.

    Methods

    process.cumulants(order: int) -> dict[int, float]
    Return cumulants κ₁, …, κ_order of X₁ (per unit time). Available for EXACT and MOMENT_PROPAGATION. Keys are integers 1..order, values are floats.

    process.char_func(u: float | np.ndarray, t: float = 1.0) -> np.ndarray
    Evaluate E[e^{iuX_t}]. Available for EXACT. For processes with a closed-form formula this delegates to char_func_exact; otherwise uses Lévy–Khintchine numerical integration.

    process.simulate(
    n_steps: int,
    n_paths: int = 1,
    T: float = 1.0,
    rng: np.random.Generator | None = None,
) -> np.ndarray
    Simulate sample paths. Returns shape (n_paths, n_steps + 1). All paths start at 0: paths[:, 0] == 0 always. For multivariate processes returns shape (n_paths, n_steps + 1, d).

    process.__story__() -> str
    Plain-text derivation trace: how this process was composed, with citations to Sato (1999) and other primary sources. Suitable for terminal printing.

    process.__story_latex__() -> str
    MathJax-ready LaTeX derivation. Returns a \begin{aligned}...\end{aligned} block. Use in Jupyter:

    The Generalized Hyperbolic (GH) Lévy process (Barndorff-Nielsen 1977; Eberlein & Prause 2002) is generated by the 5-parameter Generalized Hyperbolic distribution, representing Brownian motion subordinated by a Generalized Inverse Gaussian (GIG) process: $\(X_t = \mu t + \beta Z_t + \sqrt{Z_t} W_t, \quad Z_t \sim \mathrm{GIG}(\lambda, \delta, \gamma)\)$ where \(\gamma = \sqrt{\alpha^2 - \beta^2}\).

    Parameter Constraint Meaning
    lambda_param (or lam) \(\mathbb{R}\) Subordinator shape (\(\lambda = -1/2\): NIG, \(\lambda = 1\): Hyperbolic)
    alpha $> 0, > \beta
    beta \(\in (-\alpha, \alpha)\) Skewness / asymmetry
    delta \(> 0\) Scale parameter
    mu \(\mathbb{R}\) Location / drift parameter

    Key Properties & Subfamilies: - is_nig — True when \(\lambda = -0.5\) (Normal Inverse Gaussian) - is_hyperbolic — True when \(\lambda = 1.0\) (Hyperbolic) - subfamily — "NIG", "Hyperbolic", "Hyperbolic Cosine", or "General GH" - gamma — \(\gamma = \sqrt{\alpha^2 - \beta^2}\)

    Characteristic Function & Cumulants: - char_func(u, t=1.0) — exact characteristic function \(\phi(u; t) = \exp(t \psi(u))\) - char_exponent(u) — characteristic exponent \(\psi(u) = i\mu u + \lambda \ln\frac{\gamma}{\zeta(u)} + \ln\frac{K_\lambda(\delta \zeta(u))}{K_\lambda(\delta \gamma)}\) with \(\zeta(u) = \sqrt{\alpha^2 - (\beta + iu)^2}\) - cumulant_exact(order, t=1.0) — closed-form cumulants \(\kappa_1, \dots, \kappa_4\) derived from GIG moments - cumulants(order=4, t=1.0) — dictionary of exact cumulants

    Option Pricing: - drift_compensator() — martingale compensator \(\omega = -\psi(-i)\) (requires \(\alpha > |\beta + 1|\)) - call_price(K, T=1.0, r=0.0, q=0.0, s0=100.0) — European call option price via Gil-Pelaez Fourier inversion - put_price(K, T=1.0, r=0.0, q=0.0, s0=100.0) — European put option price via Put-Call parity - implied_volatility(K, T=1.0, r=0.0, q=0.0, s0=100.0) — Black-Scholes implied volatility

    Simulation: - simulate(n_steps=100, dt=None, time_horizon=None, n_paths=1, rng=None) — exact Inverse Gaussian subordination for NIG; fast vectorized Gil-Pelaez CDF inversion for general GH

    References: - Barndorff-Nielsen, O. E. (1977). Exponentially decreasing distributions and the normal distribution. Proc. R. Soc. Lond. A, 353(1674), 401–419. - Barndorff-Nielsen, O. E. & Halgreen, C. (1977). Infinite divisibility of the hyperbolic and generalized inverse Gaussian distributions. Z. Wahrscheinlichkeit, 38, 309–312. - Eberlein, E. & Prause, K. (2002). The generalized hyperbolic model: Financial derivatives and risk measures. Mathematical Finance — Bachelier Congress 2000, 245–267.

    Merton (1976) jump-diffusion process combining continuous Brownian motion with compound Poisson normal jump shocks:

    \[X_t = \mu t + \sigma W_t + \sum_{i=1}^{N_t} Y_i, \quad Y_i \sim \mathcal{N}(\mu_J, \sigma_J^2)\]

    where \(W_t\) is standard Brownian motion, \(N_t \sim \mathrm{Poisson}(\lambda t)\), and \(Y_i\) are independent Gaussian jump sizes.

    Parameter Constraint Meaning
    drift real, default 0.0 Continuous drift parameter \(\mu\) (alias: mu)
    sigma > 0, default 0.2 Continuous diffusion volatility \(\sigma\) (alias: vol)
    rate > 0, default 1.0 Jump arrival intensity \(\lambda\) (alias: lam, jump_rate)
    jump_mean real, default -0.05 Mean jump size \(\mu_J\) (alias: mu_j, mean_jump)
    jump_std > 0, default 0.15 Jump size standard deviation \(\sigma_J\) (alias: sigma_j, std_jump)

    Exactness: EXACT (full Lévy–Khintchine triplet and analytical characteristic exponent).

    Lévy Triplet: - \(\sigma^2 = \sigma^2\) - \(\nu(dx) = \lambda \frac{1}{\sqrt{2\pi}\sigma_J} \exp\left(-\frac{(x - \mu_J)^2}{2\sigma_J^2}\right) dx\) (finite activity, total mass \(\lambda\)) - \(b = \mu + \lambda \int_{-1}^1 x \, \mathcal{N}(x; \mu_J, \sigma_J^2) dx\) (exact closed-form error function integral)

    Extreme Value Copulas

    from spxa.copula import (
    ExtremeValueCopula,
    GalambosCopula,
    HuslerReissCopula,
)

    Max-stable copulas satisfying \(C(u_1^t, \dots, u_d^t) = C(\boldsymbol{u})^t\) characterized by the Pickands dependence function \(A(w)\): $\(C(u_1, u_2) = \exp\left( (\ln u_1 + \ln u_2) A\left(\frac{\ln u_2}{\ln u_1 + \ln u_2}\right) \right)\)$

    • GalambosCopula(theta=1.5): $\(A(w) = 1 - (w^{-\theta} + (1 - w)^{-\theta})^{-1/\theta}, \quad \lambda_U = 2^{-1/\theta}\)$
    • HuslerReissCopula(theta=1.5): $\(A(w) = w \Phi\left(\frac{1}{\theta} + \frac{\theta}{2} \ln\frac{w}{1-w}\right) + (1 - w) \Phi\left(\frac{1}{\theta} - \frac{\theta}{2} \ln\frac{w}{1-w}\right), \quad \lambda_U = 2 - 2\Phi(1/\theta)\)$

    Model Calibration & Estimation Suite (spxa.calibration)

    The spxa.calibration package provides institutional-grade cross-sectional implied volatility surface fitting, time-series econometric estimation (MLE, GMM, ECF), nonlinear latent state filtering (UKF, SMC), and diagnostic validation.

    Data Containers & Representations

    • MarketQuote(strike, maturity, value, quote_type): Single option contract market quote (implied volatility or price), with optional bid/ask, vega, forward, and discount factors.

    • SABRCalibrator: Calibrates Hagan et al. (2002) asymptotic Black-76 implied volatility smile \((\alpha, \beta, \rho, \nu)\) with bounded optimization.
    • HestonCalibrator: Calibrates Heston (1993) semi-analytical Fourier call pricing engine \((v_0, \kappa, \theta, \sigma, \rho)\) with Feller condition violation regularization.
    • BatesCalibrator: Joint calibration of Heston stochastic volatility and Merton compound Poisson jumps \((v_0, \kappa, \theta, \sigma, \rho, \lambda_J, \mu_J, \sigma_J)\).
    • DoubleHestonCalibrator: Two-factor stochastic volatility calibration \((v_{0,1}, \kappa_1, \theta_1, \sigma_1, \rho_1, v_{0,2}, \kappa_2, \theta_2, \sigma_2, \rho_2)\) capturing both short-term skew and long-term smile curvature.
    • CEVHestonCalibrator: Local-stochastic volatility model calibration combining CEV backbone elasticity \(\gamma\) with Heston stochastic variance.

    Losses & Optimizers

    • Loss functions: RMSELoss, VegaWeightedLoss, RelativeErrorLoss, ArbitragePenalizedLoss (penalizing calendar and butterfly arbitrage violations).
    • Optimization engines: LeastSquaresOptimizer (Levenberg-Marquardt / Trust-Region Reflective), DifferentialEvolutionOptimizer (global stochastic search), HybridOptimizer (global differential evolution followed by local polish).

    Time-Series Econometric Estimation (spxa.calibration.mle)

    Maximum Likelihood Estimators

    • OrnsteinUhlenbeckMLE (VasicekMLE): Analytical Gaussian exact conditional MLE for mean-reverting diffusions.
    • BrownianMotionMLE & GeometricBrownianMotionMLE: Analytical exact closed-form Gaussian log-likelihood estimators.
    • CIRMaximumLikelihood (CIRMLE): Exact transition density MLE based on non-central chi-square distribution \(\chi^2(d, \lambda)\) with Bessel-scaled modified Bessel functions \(I_\nu\).
    • BESQMaximumLikelihood (BESQMLE): Exact dimension and scale recovery from squared Bessel diffusion paths.
    • StudentTInnovationsMLE: Heavy-tailed log-likelihood optimization over \((\mu, \sigma, \nu)\) with \(t\)-distributed innovations.
    • NormalInverseGaussianMLE (NIGMLE): Exact MLE for generalized hyperbolic NIG distributions using modified Bessel functions \(K_1\).

    GMM & Spectral HAC

    • GeneralizedMethodOfMoments (GMMEstimator, GMM): Two-step optimal GMM with iterative weighting matrix update.
    • newey_west_hac: Robust Newey-West (1987) Heteroskedasticity and Autocorrelation Consistent (HAC) spectral density matrix estimator with Bartlett kernel.
    • hansen_j_test: Hansen (1982) omnibus test of overidentifying moment restrictions: \(J = N \cdot g_N(\hat{\theta})^T W_N^* g_N(\hat{\theta}) \sim \chi^2(m - k)\).
    • OrnsteinUhlenbeckGMM & CIRGMM: Multi-moment conditional expectation estimators.
    • ECFEstimator: Empirical Characteristic Function estimator minimizing integrated continuum weighted distance between sample ECF \(\phi_N(u)\) and model CF \(\phi(u; \theta)\).

    Latent State Filtering (spxa.calibration.filter)

    Unscented Kalman Filter & SMC

    • MerweScaledSigmaPoints: Scaled unscented transformation with parameters \(\alpha, \beta, \kappa\) preserving higher-order Gaussian kurtosis without negative covariance spread.
    • UnscentedKalmanFilter (UKF): Nonlinear state filtering propagating sigma points through arbitrary non-linear transitions and measurement functions with online innovation log-likelihood tracking.
    • QuasiMaximumLikelihoodEstimator (QMLE): Maximum likelihood calibration of underlying state-space parameters using UKF Gaussian innovation decomposition \(\sum_t [\ln |F_t| + v_t^T F_t^{-1} v_t]\).
    • Resampling algorithms: effective_sample_size, systematic_resample, stratified_resample, multinomial_resample.
    • BootstrapParticleFilter (ParticleFilter, SequentialMonteCarlo): Sequential Monte Carlo SIR particle filtering for general non-Gaussian/non-linear latent state spaces.

    Specialized Domain Filters

    • HestonVarianceFilter: Log-variance state-space tracker recovering latent variance \(v_t = \exp(x_t) > 0\) from realized asset returns.
    • SchwartzTwoFactorFilter: Convenience yield filter tracking unobserved commodity convenience yield \(\delta_t\) and spot price \(S_t\) from futures term structures.
    • DefaultIntensityFilter: Credit default hazard rate filter estimating unobservable hazard rate \(\lambda_t\) from observed CDS spread curves.

    Diagnostics, Standard Errors, & Reporting (spxa.calibration.diagnostics)

    Statistical Inference & Information Criteria

    • compute_numerical_hessian: High-precision central finite difference Hessian matrix.

    Two-Factor ADI

    • Grid2D(x, y): tensor grid with C-ordered unknowns, index i * ny + j.

    • TwoAssetBlackScholesPDE(r, sigma1, sigma2, rho, q1=0.0, q2=0.0): methods price(payoff, T, s1, s2, n1=101, n2=101, n_time=100, american=False, ...), exchange(T, s1, s2), spread(K, T, s1, s2, option), best_of(K, T, s1, s2) and worst_of(K, T, s1, s2).     • Values: terms(y, T), local_variance_k(y, T), local_vol_k(y, T), local_vol(K, T) and density(T, spot, r, q=0.0, n=801, n_time=400, width=8.0).
    • Links to spxa.pde: dupire_pde(r, q=0.0) and black_scholes_pde(r, q=0.0), plus american(K, T, spot, r, q=0.0, option="put", **kw) and barrier(K, T, spot, barrier, r, q=0.0, barrier_type="down-and-out", option="call", **kw).

    • dupire_local_variance(y, w, w_y, w_yy, w_T) (nan where undefined) and bbf_implied_vol(local_vol_k, k, n=401), the short-expiry Berestycki–Busca–Florent inverse. LocalVolGrid(ys, ts, variance, forward, floor=0.01, cap=3.0) and LocalVolGrid.from_surface(lv, ys, ts) tabulate it for fast lookups.
    • Andreasen–Huge interpolation:
    • calibrate_andreasen_huge(expiries, strikes, vols, grid=None, max_nodes=None, weights=None) fits piecewise-constant local-vol levels expiry by expiry.
    • It returns an AndreasenHugeFit(surface, errors, nfev) with max_error and rmse.
    • AndreasenHugeSurface(expiries, nodes, levels, grid=None) provides grid_calls(t), normalised_call(y, t) and total_variance(k, T), so it can back a VolSurface.
    • Helpers: andreasen_huge_grid(y_max=4.0, n=401, concentration=0.5) and piecewise_constant_vol(nodes_y, levels, y).
    • local_vol_paths(sigma, spot, r, q, T, n_steps, n_paths, seed=0, antithetic=True, record=None) returns LocalVolPaths with at(t), price(payoff, T) and forward_start(T1, T2, k, option="call").
    • local_vol_diagnostics(lv, spot, r, q, strikes, expiries, n_space=801, n_time=400, y_grid=None, n_t=40, reprice=True) returns LocalVolDiagnostics with errors, max_error, worst(), undefined_fraction and first_undefined_time().

    Stochastic Local Volatility

    • Heston(v0, kappa, theta, xi, rho) has feller, scaled(eta), mean_variance(t), expected_total_variance(T), cf(T), price(K, T, F=1.0, df=1.0, option="call"), implied_vol(K, T, F=1.0) and atm_short_vol(). variance_std(model, t) and variance_quantile(model, t, q) give the exact variance law.
    • slv_grid(model, T, n_y=121, n_v=61, n_sd=5.0, vol=None, v_tail=1e-6) returns an SLVGrid(y, v) with shape, weights and node(y, v).
    • slv_forward(model, grid, T, n_time=100, leverage=None, record=(), damping_steps=2) solves the two-dimensional Fokker–Planck equation with ADI. It returns an SLVForward holding an SLVDensity for each recorded time. Each density has mass, marginal(), expectation(g), forward(), conditional_variance(), call(k) and implied_vol(k).
    • Leverage calibration:
    • calibrate_leverage(local_vol, model, T, grid=None, n_time=100, record=(), ...) calibrates by forward induction, \(L^2 = \sigma_{LV}^2/E[v \mid y]\). It returns a LeverageCalibration(model, leverage, forward) with smile(k, t).
    • calibrate_leverage_particles(local_vol, model, T, n_steps=100, n_particles=50000, nodes=None, bandwidth=1.5, seed=None) is the particle method, built on kernel_conditional_mean(x, v, nodes, h). It returns a ParticleCalibration.
    • LeverageSurface(ts, ys, values) has row(t) and LeverageSurface.constant(value=1.0).
    • calibrate_slv(local_vol, heston, eta, T, n_y=121, n_v=61, n_time=100, record=(), grid=None, vol=0.2) scales vol-of-variance by the mixing fraction eta and calibrates the leverage. It returns an SLVModel with paths(T, n_steps, n_paths, **kw), pde(r=0.0, q=0.0, **kw) and smile(k, t). as_local_vol(local_vol, T, ...) tabulates a surface's local vol.
    • slv_paths(model, leverage, T, n_steps, n_paths, record=(), seed=None, antithetic=True, lower=None, upper=None, bridge=True) returns SLVPaths with at(t) and price(payoff, t, knock_out=False). Barriers use Brownian-bridge survival weights.
    • SLVPDE(model, leverage=None, r=0.0, q=0.0, n_x=161, n_v=61, n_time=100, n_sd=5.0, vol=None) provides european(K, T, option="call", spot=1.0), barrier(K, T, option="call", spot=1.0, lower=None, upper=None) and price(payoff, T, spot=1.0, lower=None, upper=None).

    Rough Volatility & VIX

    • RoughHeston(v0, theta, lam, nu, rho, hurst) has log_cf(u, T, n_steps=200), cf(u, T, n_steps=200), expected_variance(t) and heston_limit(). fractional_riccati(u, T, alpha, lam, nu, rho, n_steps=200) is the Adams scheme behind it.
    • LiftedHeston(v0, theta, lam, nu, rho, hurst, n=20, weights=None, speeds=None) has g0(t), expected_variance(t), log_cf and cf. lifted_weights(n, hurst, r=None) gives the geometric partition.
    • Both models inherit FourierPricing: price(K, T, F=1.0, df=1.0, option="call", n_steps=200, n_quad=256, u_max=20.0) and implied_vol(K, T, F=1.0, n_steps=200).
    • calibrate_rough_heston(maturities, strikes, vols, initial, free=("v0", "theta", "nu", "rho", "hurst"), forwards=None, weights=None, n_steps=400) returns a RoughHestonFit(model, vols, targets, nfev) with rmse. n_steps must keep the Adams scheme stable over the whole Fourier range; too few steps make the objective non-smooth (see the theory chapter, §10.3).
    • rbergomi_paths(hurst, eta, rho, xi, T, n_steps, n_paths, s0=1.0, seed=None, keep_variance=False) uses the hybrid scheme, with weights from hybrid_weights(hurst, dt, n). It returns RBergomiPaths with price(K, option="call", conditional=True) and implied_vol(K).
    • calibrate_rbergomi(T, strikes, vols, initial, free=("hurst", "eta", "rho"), n_steps=50, n_paths=10000, seed=0) returns an RBergomiFit with rmse.
    • HestonVIX(model, delta=VIX_WINDOW) (VIX_WINDOW = 30/365) gives VIX futures and options in closed form up to one quadrature: variance_law(T), expected_vix_squared(T), futures(T), options(T, K, option="call") and implied_vols(T, K).
    • RBergomiVIX(hurst, eta, xi, delta=VIX_WINDOW, n_nodes=24) provides:
    • exact Gaussian sampling: vix_squared(T, n_paths, seed=None), futures(T, n_paths=200000, seed=None), options(...) and implied_vols(...);
    • lognormal approximations: lognormal_moments(T), futures_lognormal(T) and options_lognormal(T, K, option="call");
    • quadrature details: xi(t), nodes(T), covariance(T) and expected_vix_squared(T).
    • calibrate_heston_joint(spx, vix, initial, weights=(1.0, 1.0, 1.0)) fits all five Heston parameters to SmileQuote(T, strikes, vols) SPX smiles and VIXQuote(T, futures, strikes, vols) VIX quotes. It returns a JointFit with rmse(part).

    Martingale Optimal Transport

    • DiscreteMarginal(points, weights) has mean, call(k), expect(f) and precedes(other, tol=1e-12) (convex order). Built by marginal_from_calls(strikes, calls, floor=None) or surface_marginals(surface, expiries, strikes) (laws of \(S_T/F_T\)).
    • mot_solve(mu, nu, payoff, sense="max"|"min") solves the linear program with HiGHS. It returns an MOTResult(value, plan, phi, psi, h, sense, mu, nu) with dual_value and hedge(x, y). mot_bounds(mu, nu, payoff) returns (lower, upper), and ot_solve(...) drops the martingale constraint for comparison.
    • mot_sinkhorn(mu, nu, payoff, sense="max", eps=1e-3, eps_start=None, tol=1e-9, max_iter=5000) is entropic MOT. It returns a SinkhornResult with the potentials and the marginal and martingale errors reached.
    • robust_bounds(surface, T1, T2, payoff, strikes, scale=1.0) returns (lower, upper, lower_result, upper_result). Ready-made payoffs are forward_start_call(k, ratio=1.0) and forward_start_straddle(k=1.0, ratio=1.0).
    • Hedges as trades:
    • static_replication(points, values) returns a StaticReplication(cash, forward, strikes, calls) with price(marginal).
    • superhedge_pnl(result, payoff, x, y) is the pathwise hedge P&L.
    • mot_multi(marginals, payoff, sense="max") handles several dates and returns (value, plan).

    Variance & Volatility Swaps

    • fair_variance(otm, T, sd=None) computes the fair variance from normalised OTM prices. variance_swap_strike(surface, T) and gamma_swap_strike(surface, T) apply the Carr–Madan replication to a surface; variance_swap_curve(surface, expiries) returns the term structure.
    • ForwardVarianceCurve(expiries, strikes) is piecewise-flat \(\xi_0(t)\), with integral(t), variance_swap(T) and forward_variance_swap(T1, T2). vix_index(surface, delta=30/365) is the model-free VIX.
    • realised_variance(log_prices, times, demean=False), variance_swap_payoff(realised, strike, cap=None) and variance_swap_mtm(realised_variance, t, T, strike, fair_remaining, df, notional=1.0).
    • heston_integrated_variance_laplace(model, T, s) and heston_volatility_swap(model, T), which gives \(E\sqrt{V_T/T}\) by the Laplace transform.
